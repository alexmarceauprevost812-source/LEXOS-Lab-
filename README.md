# LEXOS Lab Android

Prototype Android Kotlin avec fond noir, texte blanc et boutons orange.

Menu : Heretic, REA, Terminal LexOS, Atelier IA, Partage IA et Projets. Les boutons affichent pour le moment des écrans provisoires : les moteurs ne sont pas connectés. CodexLocal reste inchangé.

## Compilation

GitHub Actions > Build LEXOS Lab APK > exécution réussie > Artifacts > LEXOS-Lab-debug-APK.
